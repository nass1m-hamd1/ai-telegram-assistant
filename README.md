# AI Telegram Assistant with Memory

A personal AI bot built with **n8n**, running **100% locally** using **Ollama**.

## ✨ Features

- **7 slash commands:** `/help` `/list` `/stats` `/search` `/show` `/summarize` `/insights`
- **Persistent memory** via Google Sheets
- **Local AI** — no paid API, no cloud dependency
- **Natural conversation** with context awareness
- **Error handling** — graceful fallbacks when AI is unavailable

## 🛠 Tech Stack

| Layer | Tool |
|---|---|
| Orchestration | n8n |
| AI Engine | Ollama + qwen2.5:7b |
| Memory Storage | Google Sheets API |
| User Interface | Telegram Bot API |
| Deployment | Docker + ngrok |
